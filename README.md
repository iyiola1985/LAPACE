# LAPACE Roofing Marketplace

MVP web app built from the client's Stitch mockups and Industrial Precision design system.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What's included (Phase 1 MVP)

- Home (hero, verified pros, materials, projects)
- Find Pros directory with search + filters
- Professional profile pages
- Materials catalog with Add to Quote
- Quote request form (local basket via `localStorage`)
- Account placeholder

## Not yet included

- Real auth / contractor onboarding
- Backend API / database
- Payments
- Messaging
- Admin CMS

These wait on the real product specification from the client.
